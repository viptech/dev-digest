# server/CLAUDE.md

Package-local conventions for `@devdigest/api`. Read `server/README.md` first
for the request/DI flow, API map, and env vars — this file only holds what
isn't there. Root `CLAUDE.md` has the shared Do-not-touch list (migrations,
secrets, the grounding gate, the injection guard).

## Conventions

- **DB naming:** tables/columns are `snake_case` in SQL, `camelCase` in
  Drizzle (`headSha: text('head_sha')`). `db/schema.ts` is a barrel
  re-exporting `schema/<domain>.ts` — always import from `db/schema`, never a
  domain file directly.
- **Module shape:** `modules/<name>/` = `routes.ts` (HTTP + zod schemas) +
  `service.ts` (orchestration) + `repository.ts` (data access). When a
  module's data access grows, split it into `repository/<entity>.repo.ts`
  (e.g. `pull.repo.ts`, `run.repo.ts`).
- **Migrations:** `NNNN_name.sql`, generated by `pnpm db:generate` — never
  hand-written.
